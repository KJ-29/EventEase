# 🎉 EventEase – College Event Landing Page

**EventEase** is a modern, responsive single-page web application designed to promote and manage college events such as seminars, technical fests, workshops, and conferences.
Built with a clean UI approach and smooth user experience principles, the project focuses on structured layout design, responsive behavior, and interactive elements to enhance user engagement.

## 📌 Key Features

- 🎯 Fully responsive single-page layout
- ⏳ Dynamic countdown timer for event launch
- ✨ Smooth scrolling navigation
- 🎨 Modern UI with CSS animations & transitions
- 📱 Mobile-first design approach
- 🗂️ Structured sections for better information flow
- 🖥️ Sections Included: Home , About the Event , Event Schedule , Guest Speakers , Registration , Contact 

## 🛠️ Tech Stack

- **HTML5** – Semantic and structured markup
- **CSS3** – Flexbox, Grid, animations, responsive design
- **JavaScript** – Countdown timer functionality
